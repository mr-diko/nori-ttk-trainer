# Специфікація дизайну: Веб-додаток тренажера ТТК NORI (NORI TTK Trainer)

**Дата:** 2026-09-21  
**Статус:** Погоджено  
**Ціль:** Створити швидкий, автономний, оптимізований під смартфони та комп'ютери веб-додаток (PWA) для вивчення технологічних карт (ТТК) мережі/закладу "NORI", заснований на файлі `ТТК NORI.xlsx`.

---

## 1. Загальний огляд та цілі

Додаток призначений для кухарів-сушистів та стажерів, яким необхідно швидко та надійно вивчити склад страв, точні грамовки інгредієнтів та технологічні процеси заготовок.

### Ключові цілі:
1. **Інтервальне вивчення меню через флеш-картки** (швидке заучування рецептів за категоріями з відмітками "Знаю" / "Повторити").
2. **Розумна фільтрація декору:** автоматичне визначення інгредієнтів декору за кольором клітинки в Excel (`#E7F9EF`) та можливість відключити їх у процесі навчання, щоб сконцентруватися на базовому складі (рис, норі, риба, сир, овочі).
3. **Екзаменатор / Тестування:** перевірка знань складу та грамовок у форматі інтерактивних запитань з миттєвим формуванням колоди "Робота над помилками".
4. **Повний інтерактивний довідник ТТК:** зручний пошук по стравах та інгредієнтах з чітким візуальним розмежуванням основних продуктів та елементів декору/подачі.
5. **Автономність (PWA):** робота без підключення до мережі, можливість встановлення на головний екран смартфона, збереження прогресу в `LocalStorage` та можливість завантажити оновлений `.xlsx` файл меню.

---

## 2. Структура даних та парсинг файлу Excel

### 2.1. Вхідний файл `ТТК NORI.xlsx`
Файл містить 14 аркушів:
- **Категорії ролів та страв (102 страви):** `Філадельфія`, `Уромаки`, `Фірмові роли`, `Каліфорнія`, `Футохосомакі`, `Суші-бургери`, `Теплі, запечені, чіз роли`, `Рол доги`, `Норі роли`, `Оніґірі`, `Суші та гункани`, `Вегетаріанське АРХІВ`.
- **Заготовки (24 техкарти):** `Заготовки` — містить рецептури, співвідношення та покроковий опис приготування рису для суші, заправок, соусів, напівфабрикатів риби тощо.
- **Набори (23 сети):** `Набори 2026` — перелік ролів, що входять до кожного сету.

### 2.2. Автоматична детекція декору
- Клітинки інгредієнтів із фоном кольору **`#E7F9EF`** (79 клітинок у меню, зокрема: соуси унагі/теріякі/чилі/кунжутний, кунжут білий/чорний, ікра масаго/форель, мигдальні пластівці, мікрогрін) автоматично маркуються прапорцем `isDecor: true`.
- Користувач у налаштуваннях може переглядати та коригувати, які саме інгредієнти вважаються декором.

### 2.3. Моделі даних (TypeScript)
```typescript
export interface Ingredient {
  name: string;
  weight: string; // наприклад, "150 г", "0.75 шт"
  isDecor: boolean; // колір #E7F9EF або користувацьке налаштування
}

export interface Dish {
  id: string;
  name: string;
  category: string;
  totalWeight: string; // "290 г"
  pieces?: string; // "8 шт", "2 шт по 40 г"
  ingredients: Ingredient[];
  techProcess?: string; // для заготовок та складних страв
}

export interface SetComposition {
  id: string;
  name: string;
  category: 'Набори';
  totalWeight: string;
  pieces?: string;
  rolls: string[];
}

export interface Flashcard {
  id: string;
  dishId: string;
  title: string;
  category: string;
  totalWeight: string;
  ingredients: Ingredient[];
  notes?: string;
  status: 'new' | 'learning' | 'mastered';
  timesReviewed: number;
  timesCorrect: number;
  lastReviewed?: number; // timestamp
}

export interface CustomDeck {
  id: string;
  title: string;
  description?: string;
  dishIds: string[];
  isSmart?: boolean; // наприклад, колода "Помилки з тестів"
  createdAt: number;
}
```

## 3. Модулі інтерфейсу та функціональні вимоги

### 3.1. Верхня панель (Header)
- Назва додатка **NORI TTK Trainer** з іконкою суші.
- **Глобальний тогл «🌿 Без декору»**: миттєво вмикає/вимикає показ та тестування інгредієнтів декору по всьому додатку.
- **Перемикач теми** (Темна / Світла).
- **Кнопка швидкого вибору режиму:** Каталог, Картки, Тести, Налаштування.

### 3.2. Каталог ТТК (Довідник рецептур)
- Пошуковий рядок (пошук за назвою ролу або назвою інгредієнта, наприклад "тунець", "авокадо").
- Горизонтальний скрол або фільтр категорій (*Філадельфія, Уромаки, Фірмові, Заготовки, Набори* тощо).
- Картка страви:
  - Назва та вихід грамів.
  - Список **Базових інгредієнтів** з чіткими бейджами грамовки.
  - Блок **Декор / Подача** (візуально виділений зеленим бейджем або згорнутий при активному режимі "Без декору").
  - Кнопка **«⭐ Додати в мої флеш-картки»**.
  - Для заготовок: вкладка з покроковою інструкцією приготування та термінами зберігання.

### 3.3. Тренажер флеш-карток (Spaced Repetition)
- Вибір колоди:
  - Будь-яка категорія окремо.
  - «Всі страви» (102 картки).
  - «Заготовки» (24 картки технологій).
  - Спеціальна колода «Складні страви / Помилки».
  - Користувацькі колоди.
- Інтерактивна 3D-картка:
  - **Аверс (лице):** Категорія, назва ролу, загальна вага.
  - **Реверс (зворот):** Повний розклад грамовок основних продуктів (+ декор, якщо не відключений).
- Керування та оцінка:
  - Кнопка або свайп вліво: 🔴 **«Повторити»** (картка знову випаде в кінці раунду).
  - Кнопка або свайп вправо: 🟢 **«Знаю»** (картка переходить у статус засвоєних).
  - Прогрес-бар поточної сесії (наприклад, 8 / 20).

### 3.4. Режим тестування (Quiz & Exam)
- Налаштування тесту:
  - Вибір тем / категорій.
  - Кількість запитань (10, 20 або всі).
  - Тип тесту:
    - **«Вгадай склад»:** показано назву ролу, потрібно вибрати правильні інгредієнти зі списку запропонованих.
    - **«Вгадай грамовку»:** запитання виду «Скільки грамів [інгредієнта] кладеться в [рол]?» з 4 варіантами або числовим введенням.
    - **«Змішаний бліц-іспит»**.
- Результати:
  - Підсумковий бал (% правильних відповідей) з анімацією феєрверку (`canvas-confetti`) при відмінному результаті.
  - Список допущених помилок із правильними відповідями.
  - Кнопка **«Створити колоду для повторення помилок»**.

### 3.5. Менеджер колод та Налаштування
- **Створення власної колоди:** можливість задати назву та галочками відзначити будь-які страви з меню.
- **Керування декором:** таблиця інгредієнтів, де можна додавати чи знімати позначку декору вручну.
- **Імпорт нового файлу ТТК:** кнопка завантаження `.xlsx` для парсингу нової версії меню прямо у браузері через бібліотеку `xlsx`.
- **Резервна копія:** Експорт та Імпорт прогресу навчання у файл `.json`.
- **Очищення прогресу:** можливість скинути статистику карток і почати вивчення наново.

## 4. Технічна архітектура та стек

- **Фреймворк:** React 18 (TypeScript) + Vite.
- **Стилі:** Tailwind CSS з утилітами для 3D perspective та backface-visibility.
- **Іконки:** `lucide-react`.
- **Робота з Excel:** `xlsx` (SheetJS) для клієнтського розбору файлу.
- **Збереження даних:** `localStorage` (з автозбереженням стану, налаштувань, колод та історії).
- **Офлайн / PWA:** Service Worker / Manifest для встановлення на робочий стіл телефона.

## 5. План валідації та тестування
- **Парсинг:** Перевірка, що всі 102 страви, 24 заготовки та 23 набори зчитуються без втрати даних, а 79 інгредієнтів декору коректно маркуються `isDecor: true`.
- **Режим декору:** Перевірка, що перемикач «Без декору» миттєво ховає декор з карток, списків і виключає його з генератора тестів.
- **Флеш-картки:** Перевірка плавного перевороту 3D-картки, оновлення лічильників прогресу та збереження стану при перезавантаженні сторінки.
- **Тестування:** Перевірка генерації коректних та дистракторних відповідей, розрахунку відсотка та створення колоди помилок.
- **Мобільність:** Тестування адаптивності на розмірах екранів iPhone/Android (375px–430px) та планшетах/десктопах.
